## Dự án từ Discord

### PR Review Automation

**@bangnokia** đã tạo workflow nơi thay đổi code kích hoạt pull request reviews với phản hồi gửi qua Telegram, bao gồm đề xuất merge.

### Wine Cellar Management

Một skill local để theo dõi inventory rượu vang từ CSV exports, được xây dựng và test với 962 mục chai.

### Shopping Automation

Browser-based Tesco grocery ordering xử lý:
- Lên kế hoạch bữa ăn
- Các mặt hàng thường xuyên
- Đặt chỗ delivery slot
- Xác nhận đơn hàng

Không cần API access.

### Screenshot-to-Markdown Tool (SNAG)

Chuyển đổi vùng màn hình thành Markdown thông qua vision analysis và clipboard integration.

### Skills Management UI

Ứng dụng desktop cross-platform để quản lý commands và skills trên nhiều hệ thống agent.
